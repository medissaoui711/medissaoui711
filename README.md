I'm a **Full-Stack Developer focused on AI-powered software engineering**. I enjoy turning complex requirements into practical digital products, from frontend experiences to backend services and AI integrations.

My work emphasizes:

- **Full-Stack Development:** Building responsive applications and cohesive frontend/backend experiences.

- **Software Architecture:** Structuring maintainable systems with clear boundaries and reliable foundations.
